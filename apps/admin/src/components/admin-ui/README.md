# 后台公共展示组件

本批只适用于独立示例验证，不代表已接入或适配全部业务页面。复用既有 Vue、Element Plus 与全局主题，不包含业务请求、权限判断、业务状态映射或恢复机制。

## 使用与责任

使用者先加载现有全局主题，再加载本目录 `admin-ui.css`。不要依赖业务页面祖先类名；调用方的下拉浮层传入 `popper-class="admin-ui-popover"`。各组件可多实例组合，标题使用 Vue 的实例 ID。一个应用内保证关联唯一；多 Vue 应用同页应分别配置 `app.config.idPrefix`。

| 组件            | 输入／插槽                                                                                                                  | 输出／行为                                                                               |
| --------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| AdminPage       | `title`、可选 `description`；默认、`navigation`、`actions` 插槽                                                             | 页面唯一 h1、布局、导航位置；不读会话、不生成菜单。宽度可用 `--admin-ui-page-width` 覆盖 |
| AdminFilters    | `busy`、`disabled`、可选 `label`；默认字段和 `description` 插槽                                                             | `submit`、`reset` 无参数事件；只有表单 submit 路径触发查询，自有按钮受控禁用             |
| AdminFeedback   | 可选 `title`、`message`、`updatedAt`、`busy`、`urgent`；`tone` 为 neutral/success/warning/danger；默认内容和 `actions` 插槽 | 切换提示不卸载默认内容；urgent 使用 alert，否则 status；不隐藏、缓存或清除数据           |
| AdminPagination | 可选 `page`、`total`；`hasPrevious`、`hasNext`、`busy`、`disabled`；底部默认插槽                                            | `previous`、`next` 无参数事件；不计算页码、游标或总数，不在点击后自行更新页码            |
| AdminCopy       | `text`、可选 `label`                                                                                                        | 复制传入内容，本地提示归属当前实例；原文可选择，失败不删除；内容改变后丢弃旧异步结果     |

仅布局的工作面板使用 `section.admin-ui-panel` 与正确标题。不要重复嵌套该面板；内部分组用标题、留白、分隔线。公共状态色只传递视觉语义，不能直接按业务枚举推断红色错误。

字段全部由插槽提供。页面负责值、标签与控件 ID、校验、默认值和重置策略；示例重置后不自动查询。不要给查询按钮额外绑定 click，避免与表单 submit 重复。插槽内按钮、请求防重、业务锁定由调用方处理；公共组件禁用不能替代这些保护。

## 状态组合

- 同对象且允许展示时，页面保留数据和稳定 key，反馈提示更新中；网络失败可以标注旧数据及数据时间。
- 新查询提交后，示例清除旧列表和详情，区分编辑中与已应用条件；异步详情通过请求序号避免覆盖新选择。
- 身份／权限变化时由页面清除敏感数据；默认插槽不会替调用方缓存旧内容。
- 结果未知提示与普通读取失败分开组合。页面负责原请求、账号校验和离开保护；组件仅展示摘要及核实入口，不自动重试写入。
- 操作成功与刷新失败、保存成功与待办可以同时展示，不合成单一互斥状态。
- 列表／详情结构、选择、滚动及焦点恢复由示例负责。正常刷新保留节点，切换对象可以卸载旧详情。
- 页面也负责失败路径的位置恢复：接待详情失败时定位反馈与返回入口；请假提交和核实完成后，结果保留在影响操作区并由页面聚焦。公共反馈组件不自动移动焦点。
- 请假示例按字段显示错误、关联实际输入并定位首个错误；没有抽象字段配置或表单引擎。Element Plus 日期控件未透传的原生输入 ARIA 属性由示例本地适配。

## 分页与追加

上一页／下一页通过已取得结果更新 `page`，失败不提交新页码。未知总数不传 `total`，不得用已加载条数冒充。
尚未取得本次查询结果时不提供页码，也不允许前后翻页；重试读取成功后恢复分页并清除失效的错误提示。

追加模式在列表底部组合按钮和 AdminFeedback：首次失败展示无数据；追加失败保留原列表；按钮触发页面的读取函数；无更多记录时展示“已全部加载”。不统一或更改后台已有分页方式。

## 默认尺寸与例外

本轮精修约定以舒适扫读为目标，不以首屏字段数、记录条数或固定行高验收。遵循同一对象信息靠近、对象之间明确分隔；长文本与异常内容自然换行，禁止截断关键安排、风险或编号。

| 项目       | 默认约定                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 字号层级   | 页面主标题桌面 30px、560px 以下 28px，行高 1.3；面板标题 20px/1.4；记录对象 16px/1.5；正文与控件 14px；辅助说明 13px；次要编号 12px     |
| 留白       | 普通页面最大宽度 1240px；桌面页边 32px、面板间距 24px、面板内边距 24px；窄屏页边 16px、面板内边距 18px。字段间隔 20px；记录不设固定高度 |
| 控件       | 字段、按钮圆角 9px，面板 16px，状态保留胶囊；主控件至少 44px；字段左右内边距 12px，文本域可自然增高                                     |
| 中性色     | 输入值与正文 #203128；辅助 #647168；占位符 #68776d；禁用值 #78847d、底色 #f0f3f1；默认边界 #cbd5ce、悬停边界 #98aca0                    |
| 交互状态   | 聚焦边界森林绿，键盘焦点保留可见外圈；错误边界使用 `--danger` 并配合具体文字与输入关联；原生时间输入与 Element Plus 使用同一组局部变量  |
| 状态与选择 | 正常信息、日期、历史状态以中性色呈现；关注项橙色、明确失败红色、明确成功绿色；选择关系使用 #f1f3f2 浅底与 #9ca8a0 边线，不借用成功底色  |

变量只设置在 `.admin-ui-page`、`.admin-ui-review` 与 `.admin-ui-popover` 范围。浮层须显式传 `popper-class`。调用方明确指定状态语义；接待示例将列表与详情的同一状态交给同一映射函数，公共组件不判断业务状态。保存后的待办汇总一次，不继续堆叠提交前影响提示；未知结果的核实入口与原操作摘要始终相邻。

关键时间、金额、影响与禁用原因保持正文可读性。接待示例 820px 转单栏，表单 900px 转单栏。二维日历应使用独立滚动区，不裁切整页。日期面板沿用 Element Plus 紧凑日期单元格，主输入区域仍为 44px；窄屏浮层单独限制宽度。尺寸记录不能代替真实浏览器 200% 缩放验收。

## 开发预览

从仓库运行 `pnpm --filter @dexian/admin dev --host 127.0.0.1 --port 5175 --strictPort`，通过 `http://127.0.0.1:5175/ui-preview.html` 访问。不要双击 HTML。

入口独立初始化 Vue 和中文 Element Plus，只读取已有样式，不导入业务 main、router、会话或 API。顶部评审控制区明确“重置演示并应用”，与模拟工作区保护分开。两种示例使用固定虚构记录和内存延迟，模拟时间固定；不实现真实业务或跨刷新持久恢复。

运行 `pnpm --filter @dexian/admin test`、`pnpm --filter @dexian/admin typecheck` 验证。生产构建仅覆盖生产依赖链，必须另外实际打开示例检查真实控件、焦点、浮层及布局。生产目录不得包含 `ui-preview.html` 或 `DEXIAN_ADMIN_UI_DEMO_ONLY_20260912`。
