## 本轮评审方向与实现

按用户评审方向，继续沿用 [DESIGN.md](../DESIGN.md) 的森林绿、浅色底和白色工作面板，以充分留白、清楚的处理顺序和稳定的信息层级服务运营人员，不追求单屏记录密度。页面最大宽度仍为 1240px，不扩展布局骨架，也不另立全局设计体系。

| 项目       | 本轮实现                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 字体层级   | 页面标题桌面 30px、手机 28px；面板标题 20px；列表对象名称 16px；正文 14px；辅助说明 13px；列表编号 12px。关键时间、金额、影响和禁用原因不降为说明小字          |
| 字段与按钮 | 圆角统一为 9px，主操作区最小高度 44px，可自然增高；统一字段内边距、文字、边界、悬停、聚焦和禁用样式；字段错误使用明确文字、边界及输入关联                      |
| 面板与留白 | 面板圆角 16px，桌面内边距 24px、窄屏 18px；保留双栏间距和纵向阅读顺序，列表对象、时间、项目、编号与查看动作分层呈现                                            |
| 状态语义   | 状态色由调用方明确映射，列表与详情一致：待确认橙色、已确认绿色、已过期中性；日期使用普通说明文字。当前选中记录使用中性浅底和描边，避免把选中态混同成功状态     |
| 请假结果   | 影响区集中承载处理结果；保存后只显示一次明确结果，以及必要时一次人工待办，替换保存前影响摘要。结果未知时仍保留原操作、受影响接待及核实入口；锁定与核实保护保留 |
| 评审控制区 | 可收起和展开，保留“虚构数据 · 不连接业务服务”标识；折叠只影响评审设置，不重置进行中的工作；“重置演示并应用”继续明确说明会清空模拟操作                          |
| 长文本     | 增加“长名称、长编号与项目”虚构场景，检查 320px 下列表、选中记录、详情及编号换行；操作入口不依赖截断文字表达                                                    |

样式依据为 [admin-ui.css](../apps/admin/src/components/admin-ui/admin-ui.css) 与 [preview.css](../apps/admin/src/dev/admin-ui/preview.css)，行为依据为 [接待示例](../apps/admin/src/dev/admin-ui/ReceptionExample.vue)、[请假示例](../apps/admin/src/dev/admin-ui/LeaveExample.vue) 和 [评审控制区](../apps/admin/src/dev/admin-ui/PreviewApp.vue)。接待 820px、请假 900px 转单栏的规则不变；日期浮层继续采用局部宽度约束，日期格沿用 Element Plus 紧凑尺寸。
